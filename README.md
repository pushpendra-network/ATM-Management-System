# ATM Management System

## Overview
A console-based ATM Management System developed in C++ using Object-Oriented Programming and File Handling.

## Features
- Create Account
- Login Authentication
- Deposit Money
- Withdraw Money
- Check Balance
- Change PIN
- Delete Account
- Transaction History
- Persistent Data Storage

## Technologies Used
- C++
- OOP
- STL Vector
- File Handling

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Static Members
- Member Functions

## How to Run

g++ main.cpp -o atm
./atm
